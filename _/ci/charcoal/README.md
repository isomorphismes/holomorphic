# Charcoal application chrome

All maintained APK and bundle producer jobs stage the shared native Android
resources from android-NDK source
`3e682fb1175beef5625dbd2418730220e49fc9bd`. The manifest explicitly selects
the charcoal launch, splash, bar and icon policy; the activity retains fullscreen
landscape presentation. For a direct local build, stage the same resources into
`android/app/src/main/res/` before the existing Android build.

The maintained checked shader source and explicit legacy-reference template use
the same neutral control roles: selected surface `#383838`, other surface
`#2F2F2F`, primary mark `#F4F4F4` and secondary mark `#B4B4B4`. Control interiors
are opaque so their contrast does not vary with the scientific field behind
them. Their shapes, positions, selection state and hit targets are unchanged.
The Wegert coloring source, complex function, numeric readback paths, evolution,
zero/pole identities and plotted-field colors are unchanged.

The checked fragment producer uses Flexible Pipes source
`9531b31de8a3f5dd41f8083dd2ecdd1293e31628`, stacked on its canonical Grease
entrypoint correction. Its available engine archive contains exactly the
previously pinned host binary; no compiler, mathematical acceptance or tolerance
is replaced. This application's packaging/emulator runtime archive is repaired
with the same byte identity.

Pull-request checks retain signed candidates and evidence as workflow artifacts.
The existing automatic qualification release is restricted to explicit workflow
dispatch because this work authorizes no release publication. Store publication
and the native release workflow retain their existing manual boundaries.

Source/build, emitted-GLSL execution, numeric/color parity, visual control
acceptance and physical C67 acceptance are separate results. API 29/34 both-mode
control samples, startup frame sequences, rotation and physical C67 behavior
remain outstanding until the corresponding exact-candidate receipts exist.
The scientific canvas is an intentional exception to whole-frame dark coverage.
